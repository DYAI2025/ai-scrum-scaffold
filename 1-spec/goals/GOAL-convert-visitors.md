# GOAL-convert-visitors: Convert visitors into paying customers

**Description**: Guide visitors through the scroll-driven funnel — from first impression to paid astrology reading. The landing page must build enough trust and intrigue that users are willing to pay before seeing their full reading.

**Status**: Approved

**Priority**: Must-have

**Source stakeholder**: [STK-founder](../stakeholders.md)

## Success Criteria

- [ ] Complete user flow from Hero → path selection → birth data input → paywall → checkout works end-to-end
- [ ] Payment integration (Stripe or equivalent) accepts real transactions
- [ ] Both character and partnership paths lead to a conversion point
- [ ] Sample/teaser content demonstrates value without giving away the full reading
